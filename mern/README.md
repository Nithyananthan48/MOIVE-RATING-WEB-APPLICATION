# Movie Da – MERN Stack Movie Discovery & Rating Platform

Full documentation, system architecture, API endpoints, and guides are available in the root [README.md](../../README.md) and [PROJECT_REPORT.md](./PROJECT_REPORT.md).

### Quick Start
```bash
# Start backend server
cd server
npm install
npm run dev

# Start frontend client (in another terminal)
cd ../client
npm install
npm run dev
```

- **Backend**: http://localhost:5000 (Health Check: http://localhost:5000/api/health)
- **Frontend**: http://localhost:5173
